# Lamborghini donor download

The original extracted Blender source and textures are included under `original/source/Lamborgini/`. Duplicate ZIP archives and outer texture copies are excluded from Git. Source:

[Lamborghini Murcielago LP-640 – Low Poly by Ajay Gawde](https://sketchfab.com/3d-models/lamborghini-murcielago-lp-640-low-poly-1822aaadc6f34060a38ddf46f0c84ec3)

The model is listed as 11,000 triangles under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Keep the original source and attribution when adapting it. The active high-detail white thruster conversion is saved separately in `Art/AstraLP640_HD.blend`; its exported version is in `Unity/Assets/AstroQuest/Art/DonorVehicle.fbx`. See the workspace `CREDITS.md` for modification details.
